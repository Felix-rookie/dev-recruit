## 阶段一：付费测试任务（1,500 元 / 1-2 天）

**目标**：验证开发者对接金蝶 + n8n 编排能力

- 完成金蝶云星辰 API 鉴权对接（签名生成、Token 获取、缓存刷新）
- 跑通一条端到端查询链路（即时库存查询）
- 输出：单条 n8n 工作流 + 企微回复格式化

## 阶段二：核心功能开发（7,000 元 / 3-5 天）

**目标**：完成全部业务查询场景

- 销售数据查询工作流（按客户/时间查询订单与出库）
- 采购进度查询工作流（按供应商/采购单查询到货入库）
- OpenClaw 意图识别 Prompt + Tool 定义（意图解析、槽位提取）
- 异常处理机制（物料模糊匹配、API 超时、无权限等友好提示）
- 数据安全与权限（可选：按 UserID 限制查询范围）

## 阶段三：联调测试与交付（2,500 元 / 1-2 天）

**目标**：全链路验收、输出交付物

- 端到端联调测试
- 场景测试案例编写与验证
- 交付物归档：
  - n8n 工作流定义文件（.json）
  - OpenClaw 配置说明文档
  - 接口与字段映射表
  - 测试与联调报告

## 阶段四：质保期（2,000 元）

- 验收后 30 天内 Bug 修复及小修小改
- 质保期结束后支付尾款

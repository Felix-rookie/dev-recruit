## 🤝 合作流程

1. **需求对齐** — 在本仓库 Issue/Discussion 中讨论需求和细节
2. **技术方案确认** — 确定技术栈、架构和交付标准
3. **付费测试任务** — 小型独立模块（1-3天工作量），评估代码质量与协作
4. **正式合作** — 按里程碑分期交付与结算

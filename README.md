## 🎯 首期功能

| 场景 | 说明 |
|:---|:---|
| 即时库存查询 | 按物料名称/编码查实时库存及分仓库存 |
| 销售数据查询 | 按客户/时间查订单与出库记录 |
| 采购进度查询 | 按供应商/采购单号查到货与入库状态 |

## 🔧 核心栈

- **前端入口**：企业微信（自建应用）
- **AI Gateway**：OpenClaw（意图识别 / Function Calling）
- **编排层**：n8n（工作流编排 + 金蝶 API 对接）
- **底层 ERP**：金蝶云星辰（已开通 API 权限）

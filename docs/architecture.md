## 数据流简述

1. 员工在企微发送自然语言消息
2. OpenClaw 接收消息，通过大模型解析意图并提取关键参数
3. OpenClaw 调用 n8n 对应工作流（Function Calling），传递提取后的参数
4. n8n 执行鉴权 → 组装请求 → 调用金蝶云星辰 API
5. n8n 接收返回结果，清洗冗余数据，格式化为 Markdown/卡片消息
6. 返回结果至 OpenClaw，通过企微 Gateway 回复员工
7. 异常情况（模糊匹配/超时/无权限）返回友好提示文本
